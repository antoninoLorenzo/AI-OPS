# Storage Layout

## Directory structure

```
~/.local/share/ai_ops/
├── user_skills/           # External markdown skills provided by the user
├── workspace/             # The live working directory for agent file operations
│   └── <conversation>/    # Per-conversation workspace (WriteFile, Terminal cwd)
├── conversations/         # Persisted conversations (one directory per conversation)
│   └── <uuid>/
│       ├── messages.jsonl
|       └── events.jsonl
├── index.json             # short_id -> conversation uuid map
├── ai_ops.log             # Runtime logs generated by the application
└── agent_config.json      # optional user provided configuration for the agent
```

## Conversation store

Conversations are handled through the conversation store abstraction (`ai_ops.core.conversation`).

| Implementation | Persistence | Notes |
|---|---|---|
| `InMemoryConversationStore` | None | **Current default** of `get_conversation_store()` |
| `JSONLConversationStore` | `conversations/<uuid>/messages.jsonl` | Appends each message as a line; `index.json` maps the human-friendly `short_id` to the conversation `uuid` |

Select the backing store explicitly via:

```python
get_conversation_store(strategy=StorageStrategy.JSONL)
```

## Event store
 
The structured event stream `AgentRunner.arun` yields (`TextEvent`, `ToolCallEvent`, `ToolResultEvent`, etc.) is persisted separately from messages, through `ai_ops.core.event_store`. It shares the same `StorageStrategy` enum as the conversation store (`ai_ops.core.conversation.StorageStrategy`).
 
| Implementation | Persistence | Notes |
|---|---|---|
| `InMemoryEventStore` | None | **Current default** of `get_event_store()` |
| `JSONLEventStore` | `conversations/<uuid>/events.jsonl` | Appends each event as a line (`event.model_dump_json()`) |
 
Select the backing store explicitly via:
 
```python
get_event_store(strategy=StorageStrategy.JSONL)
```

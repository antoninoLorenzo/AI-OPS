## Overview

This document covers the configuration settings for AI-OPS API. The API is containerized using Docker and its configuration is managed via environment variables passed as Docker build arguments. These settings determine how the API connects to the Ollama service for LLM inference.

## Environment Variables

The API currently uses the following environment variables:

| Variable | Description |
|----------|-------------|
| MODEL    | Specifies the model name used by the AI assistant, that must match the exact model name as recognized by Ollama. <br> *Default value: `mistral`* |
| ENDPOINT | Defines the endpoint where the Ollama service is running.  <br> *Default Value: `http://localhost:11434` |

> If you took a look at the code, you can see there are other environment variables going around. However only `MODEL` and `ENDPOINT` are currently relevant.

## Docker Build and Run

The Docker build arguments map one-to-one with the API's environment variables. When deploying the Docker container, specify the model and endpoint as follows:

```bash
docker build -t ai-ops:api-dev --build-arg ollama_endpoint=YOUR_ENDPOINT --build-arg ollama_model=YOUR_MODEL .
docker run -p 8000:8000 ai-ops:api-dev
```

## CLI Behavior

The AI-OPS CLI is designed to interact with the API, so if it's not reachable, the following message is displayed:

```bash
Backend: offline
```

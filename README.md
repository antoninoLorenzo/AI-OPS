## Overview

AI-OPS is a **Penetration Testing AI Agent** 

Focus on accessibility 

Use Cases: Code analysis, ...

As any other AI tool, it doesn't replace either competence or knowledge


### Features

Bring-Your-Own-LLM: uses [`litellm`](https://github.com/BerriAI/litellm/) under the hood so you can use whatever LLM API you want.

Observability: connect with AI observability platforms, currently only MLFlow
